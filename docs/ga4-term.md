GA4 주요 지표 용어 정의
서비스별 이용 현황을 동일한 기준으로 분석하기 위해 GA4 주요 지표를 정리했습니다.
1. 이벤트 수 (Event count)
• 정의: 사용자가 웹·앱에서 발생시킨 이벤트의 총횟수
• 예시: 페이지 조회 3회 + 버튼 클릭 2회 = 이벤트 5회
• 활용: 기능별 이용량 분석 (식단 기록, 상담사 검색 등)
2. 세션 수 (Sessions)
• 정의: 사용자가 웹·앱에 방문하여 활동한 세션의 수
• 예시: 오전 1회 + 오후 1회 방문 = 세션 2회
• 활용: 서비스 방문 빈도 분석
• 참고: 기본적으로 30분간 활동이 없으면 세션이 종료됨
3. 사용자 수 (Total users)
• 정의: 측정 기간 동안 이벤트를 발생시킨 중복 제거 사용자 수
• 예시: A가 5회 방문, B가 3회 방문 = 사용자 2명
• 활용: 전체 서비스 이용 규모 파악
4. 활성 사용자 수 (Active users)
• 정의: GA4의 활성 사용자 판정 기준을 충족한 중복 제거 사용자 수
• 예시: 10초 이상 이용하거나 주요 이벤트를 발생시키는 등 참여 조건을 충족한 사용자
• 활용: 실질적인 서비스 이용 규모 및 MAU 분석

:pushpin: 활성 사용자 판정 기준
다음 중 하나에 해당하면 활성 사용자로 집계될 수 있습니다.
• 참여 세션이 발생한 사용자
• 최초 방문(first_visit) 또는 최초 실행(first_open) 이벤트가 발생한 사용자
• 참여 시간(engagement_time_msec) 정보가 수집된 사용자
※ 참여 세션은 기본적으로 10초 이상 이용, 주요 이벤트 발생, 페이지·화면 조회 2회 이상 중 하나를 충족한 세션입니다.

:pushpin: 핵심 정리
• 이벤트 수 = 얼마나 많이 행동했는가?
• 세션 수 = 얼마나 자주 방문했는가?
• 사용자 수 = 몇 명이 이용했는가?
• 활성 사용자 수 = 몇 명이 실질적으로 참여했는가?

:warning: 분석 시 유의사항
GA4의 일반적인 '사용자(Users)' 지표는 보고서에 따라 활성 사용자 수를 의미할 수 있습니다. 따라서 리포트 작성 시 *전체 사용자 수(Total users)*와 *활성 사용자 수(Active users)*를 구분해서 사용해야 합니다.
